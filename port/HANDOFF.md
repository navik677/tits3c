# HANDOFF: порт русика ZoG (PC) → PS Vita «Trails in the Sky the 3rd» (PCSG00490)

Репозиторій: https://github.com/navik677/tits3c (лише інструменти й документація; ігрові дані не залиті).
Останнє оновлення: 2026-11-26 (Linux-ПК, Fedora/KDE).

## Мета
Перенести російський переклад ZoG з PC-версії на Vita-версію (English v1.0, NoNpDrm) через плагін rePatch:
файли в `ux0:rePatch/PCSG00490/` перекривають вміст гри.

## Поточний стан (перевірено в Vita3K)
- ✅ **Діалоги російською рендеряться в грі** (перша сцена New Game: «От лица компании "Конрад"…»), пропорційним шрифтом.
- ❌ **Рядки задовгі**: розриви `0x01` взято з PC-версії, кирилиця на Vita ширша → текст вилазить за рамку діалогу. Головна задача наступної сесії.
- ❌ Інтерфейс (меню, предмети, імена, квести, книги) — англійський.
- ⚠️ 3996 із 19720 реплік лишилися англійськими (не зіставились).
- ⚠️ Ё/ё виводяться як Е/е (див. «Кодування»).

## Ключові технічні факти
### Кодування тексту Vita = Shift-JIS (не UTF-8!)
Англійські `msg/*.mbin` містять `81 5C` (―), `81 40` (широкий пробіл) тощо.
- Двобайтова кирилиця JIS X 0208 (`0x8440..0x8491`) у шрифті є, **але гра виводить двобайтові символи з фіксованим широким кроком** → літери урозрядку. Відкинуто.
- **Робоча схема: однобайтові слоти півширинної катакани.** `А..Я` (без Ё) = `0xA0..0xBF`, `а..я` = `0xC0..0xDF`. Рівно 64 слоти → Ё/ё мапляться на Е/е. Однобайтові символи гра виводить пропорційно (крок = ширина гліфа).
- Енкодер: `tools/sjis.js` (`CYR_MODE=double` — старий двобайтовий режим, для експериментів).

### Шрифт `data_3rd/system/vitafont2bit.fnt` (VFNT)
- Заголовок `VFNT`; таблиця діапазонів: start @0x40, end @0x80, базовий індекс гліфа @0xC0 (u32 ×16). Діапазони: `0x00–0x7F`→0, `0x8141–0x9FFC`→0x80, `0xE040–0xFC4B`→0x1F3C, `0xA0–0xDF`→0x3B48. Індекс = base + (code − start).
- @0x100: u32 кількість гліфів (0x3B88), далі u32 на гліф: старший байт = ширина (px), молодші 24 біти = зсув бітмапа від `0x104 + 4*count`.
- Бітмап: висота 32, 2 bpp, **по стовпцях** (8 байт на стовпець).
- `tools/font_patch.js` перенаправляє 64 слоти `0xA0..0xDF` на наявні кириличні гліфи (`0x8440..`). Бітмапи не копіюються.
- Кириличні гліфи ширші за латинські (`А` 22 px проти `A` 14 px; `а` 16 проти `a` 11).

### Ширина рядків (заміряно за шириною гліфів)
- EN: медіана 207 px, p99 439, p99.9 513, максимум 584.
- RU (поточний): медіана 284, p99 775, максимум 1078; ~15 тис. рядків > 513 px.
- На скріншоті рядок ~640 px вже обрізається рамкою. Орієнтовний ліміт ≈ 500–520 px (точно підібрати в грі).

### Формати
- `msg/*.mbin`: u32 count; count×(u32 kind=1, u32 offset); зсуви відносно `4+8*count`. Запис = 3-байтова голова (`00 nn 01/00`) + `#коди` + текст, `01` = новий рядок, сегменти (сторінки) розділені `02 03`, кінець `02 00`.
- PSARC v1.4 zlib (`repatch/…/data*.psarc` — розшифровані; `app/…` — PFS-шифровані).
- Гра шукає спершу розпаковані файли в `/arc/...` (у Vita3K це помилки «Cannot find device» — норма), потім у psarc.
- `repatch/eboot.bin` — SELF (заголовок `SCE`), рядки в ньому не читаються напряму (стиснутий/шифрований).

## Збирання (Linux)
З теки `port/`:
```sh
R=".../repatch/PCSG00490/gamedata"
node tools/psarc_extract.js "$R/data.psarc" vita/data data_3rd/msg/ data_3rd/text/ data_3rd/system/   # префікси — фільтр
mkdir -p out/overlay/data_3rd/system
node tools/font_patch.js vita/data/data_3rd/system/vitafont2bit.fnt out/overlay/data_3rd/system/vitafont2bit.fnt
node tools/conv_msg.js out/overlay/data_3rd/msg
node tools/psarc_build.js "$R/data.psarc" out/overlay out/rePatch/PCSG00490/gamedata/data.psarc ""
```
Фінальний пакет: `out/rePatch/PCSG00490/gamedata/data.psarc` (наш) + `data0.psarc` і `eboot.bin` з repatch.

## Тестування у Vita3K (Linux)
- Vita3K: `~/Downloads/Vita3K-x86_64.AppImage` (v0.2.1, Qt-GUI). Прошивка встановлена. VitaFS: `~/.local/share/Vita3K/Vita3K/`, лог: `~/.cache/Vita3K/vita3k.log` (або stdout).
- Гра встановлена в `ux0/app/PCSG00490` (через GUI: File → Install .zip, з оригінального zip; CLI-встановлення в цій збірці не працює; урізаний zip без psarc не встановлюється — розшифровувач хоче всі файли).
- Патч накладено **прямо в `ux0/app/PCSG00490`** (reflink-копії: eboot.bin, gamedata/data.psarc, data0.psarc). Також є копія в `ux0/patch/PCSG00490` (не перевірено, чи Vita3K її використовує).
- Оновлення архіву без зупинки гри: `cp --reflink=always out/.../data.psarc $A/data.psarc.new && mv $A/data.psarc.new $A/data.psarc` (новий inode), потім перезапуск.
- Запуск: `Vita3K-x86_64.AppImage -r PCSG00490`. Скріншот: `spectacle -b -n -f -o shot.png` (grim не працює на KDE). Ввід у гру Claude робити не може (немає xdotool/ydotool) — клавіші натискає користувач (Enter = Start, X = ✕).
- Диск `/home` btrfs — reflink-копії безкоштовні; місця мало, стежити за `df`.

## Наступні кроки (за пріоритетом)
1. **Автоперенесення рядків** у `conv_msg.js`: прибрати PC-розриви `01` у межах сегмента і заново переносити по словах за піксельною шириною (ширини з VFNT; ліміт ≈ 500 px, підібрати в грі). Враховувати, що сторінка (сегмент) має максимум рядків як в англійській (зазвичай 3); якщо не влазить — ділити на нові сегменти `02 03` з тими ж `#кодами` (або зменшити ліміт/шрифт).
2. **Таблиці інтерфейсу** `data_3rd/text/t_*._dt` (62 файли; англ. `t_name`, `t_item`, `t_quest`, `t_book*`, `t_town`, …): у PC-русику відповідники — `ru_pc_dec/ED6_DT22/T_*._DT` (72 файли). Структура: u16-таблиці зсувів + пул рядків; при заміні тексту перераховувати зсуви. Писати SJIS через `tools/sjis.js`.
3. Інші джерела тексту: `ED6_DT30` (512 файлів, `AS*._DT` — ймовірно бойові скрипти/навички), `ED6_DT3A` (289) — з'ясувати, що там і чи є Vita-відповідники. Тексти меню, вшиті в `eboot.bin` і текстури (`*.itp`, напр. `etc/c_*.itp`), — окреме дослідження.
4. Підвищити покриття діалогів (3996 англійських): покращити `align.js`; 22 записи відкинуто через биті байти `0xA2/0xA3` у PC-даних.
5. Ё: за бажанням знайти ще один вільний однобайтовий код (напр. `0x80`, `0xFD–0xFF`, якщо гра їх не трактує як lead-байти) і додати діапазон у VFNT.
